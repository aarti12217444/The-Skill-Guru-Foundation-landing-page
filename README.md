# 🚀 The Skill Guru Foundation - Web Development Internship Landing Page

A modern and responsive landing page created for **The Skill Guru Foundation** to promote the **Web Development Internship Program**.  
This project is designed with a professional UI, smooth animations, theme toggle, and mobile responsiveness.

---

## 📌 Project Overview

This landing page helps students explore and apply for the internship program.  
It highlights the organization, skills offered, benefits, and contact section in a clean and engaging format.

---

## ✨ Features

- 🌗 Light Mode / Dark Mode Toggle  
- 📱 Fully Responsive Design  
- 🎬 Video Background Hero Section  
- ⚡ Smooth Animations using AOS & GSAP  
- 🧑‍💻 Skills Showcase Cards  
- 📋 Internship Benefits Section  
- 📩 Contact Form  
- 🎨 Modern UI with Professional Styling  
- 🔗 Smooth Navigation Scroll  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript  
- AOS Library  
- GSAP Animation Library  
- Font Awesome Icons  
- Google Fonts
